# Raven Hub

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Aekkalak667/RavenHub-Release/main/loader.lua"))()
```

The loader selects the supported game automatically. Right Shift shows/hides the hub.

| Game | Game ID | Version | Features |
| --- | --- | --- | --- |
| Clean all the Leaves | 10539411000 | 1.0.1 | Auto collection, selling, equipment and upgrades |
| ENTRENCHED | 1281592938 | 1.1.0 | Enemy ESP and filters, aim settings, local recoil/spread controls, themes |

ENTRENCHED: enter a match and equip a supported gun. Air Walk, flight, noclip and instant head-hit experiments are excluded. Aim changes are not a guarantee of server damage.

Only distribution payloads are published here. Editable authoring source stays in the author's local workspace. Payloads use obfuscation and reversible encoding; client-side code can be recovered. No key system or paid access is included.
